# ADR 0002 · 首版审查结果的适用范围

日期：2026-10-28。状态：已接受。依据：用户在本轮讨论中确认以下三项建议。本记录确认产品规则，不表示所有对应交互已实现或验收。

## 决定

| ID | 条件 | 首版规则 |
| --- | --- | --- |
| AP-001 | 文件只改名，双侧文本未变 | 要求重新审查，不自动迁移旧路径的人工结论。路径变化可能影响导入、配置和引用。新路径没有结论时可显示 pending；不要求一定显示 recheck。 |
| AP-002 | 文件自身未变，其他文件、依赖或配置改变 | 人工文件标记仅保证该文件自身比较材料的审查状态，不自动据此宣称关联影响已检查。界面需明确说明这一范围，并允许人主动发起复审。暂不引入依赖图自动失效。 |
| AP-003 | HEAD 引用改变，但该文件基线与当前内容均未变，且工作区和路径未变 | 保留人工判断；Agent 报告中受指纹变化影响的意见暂时标旧、禁止直接采纳。历史报告保留；不将历史成功运行改成失败。后续如统一匹配政策，另作决定。 |

人工判断针对固定双侧比较材料。仅 stage/unstage 不失效；双侧内容实际变化需复审；Agent 不能代替人批准。这些既有不变量继续有效。

## 实现边界

- AP-001：当前人工结论按路径存储，不自动迁移至新路径；继续保持该行为。本轮未新增重命名迁移机制。
- AP-002：当前有单文件/整批 Agent 审查入口；跨文件影响的范围提示是否足够明确，仍需在可用性验证中核对。不能把规则文档当作界面已满足要求的证据。
- AP-003：当前人工内容摘要不包含 HEAD，Agent fingerprint 包含 HEAD，符合两种匹配政策的方向。这里“报告标旧”具体落实为其意见相对当前快照的 stale 状态，不改写历史 run。

本轮仅同步文档与图谱，不修改生产算法、不推进 BACKLOG 状态。内容缺席与空文本折叠、未知内容判断等正确性缺口仍见 [本体分析](../ONTOLOGY.md)，不因上述规则确认而视为已修复。

## 后续决策边界

工作区搬迁身份、跨 run 缺陷归并、rename 后自动迁移判断，以及依赖上下文的自动失效，仍需后续需求与实现证据。当前规则不推断跨时间的逻辑文件身份，也不承诺局部已审查意味着整批修改正确。
